# Eye Saver — Google Play listing copy

## App name

Eye Saver

## Short description

Parent-controlled screen time, app breaks and private distance reminders.

## Full description

Build healthier screen habits on a shared Android phone without constant arguments.

Eye Saver gives parents one simple place to choose a session length, select the apps covered when time ends, and start a protected child session. The active-screen timer pauses when the display is off, so only real viewing time counts.

Key features:

- Parent PIN protects settings and stops an active child session.
- Choose which apps are covered after screen time reaches zero.
- Full-screen break overlay appears above selected apps.
- Calls can remain available by leaving the Phone app unselected.
- Optional viewing-distance reminder uses on-device front-camera analysis.
- Adjustable distance threshold and battery-friendly analysis interval.
- Optional Settings and app-install protection during child mode.
- Visible Android notifications show whenever background protection is active.
- Guided one-tap setup opens the exact Android permission pages.
- No ads, no account, no analytics and no cloud upload.

Privacy by design

Optional camera frames are analysed only on the phone and are never saved as photos or video. Usage access is used to identify the currently open app while protection is active. Eye Saver does not upload app history or camera data.

Important limitations

Eye Saver is a parent-guided wellbeing tool, not a medical device. Camera distance is approximate and can vary by face, angle, lighting and phone camera. Android allows the device owner to Force Stop ordinary apps; strongest tamper resistance requires Device Owner provisioning on a dedicated child phone.
